# V1 基础监控看板

该版本完成电脑端对 RDK 真实数据的集中显示，并提供 ESP32 对话回顾、单句情绪线索和会话总结。

## 数据接口

- 画面：RDK `web_fall.py` 的 `/video_feed`
- 行为状态：RDK `web_fall.py` 的 `/alert_status`
- 温度和环境数据：RDK `web_fall.py` 的 `/api/iot_payload`

页面不生成模拟温度或空气质量数据；接口缺失的数值显示为 `--`，接口异常通过页面状态栏提示。

## 运行

配置上游数据接口地址后，在 Windows 终端运行：

```bat
cd /d D:\ESP32\tongyu-zhishu-v1\dashboard
conda activate xiaozhi-esp32-server
set RDK_BASE=http://192.168.43.54:5000
python server.py
```

浏览器打开 <http://127.0.0.1:8088>。

本机对话页为 <http://127.0.0.1:8088/chat>。小智服务启动后，对 ESP32 说话即可查看识别文字、回复、情绪标签与需留意的会话；最近 200 条记录会保存在本机。

“智能分析设置”可控制：

- 对话总结是否使用模型，以及复用小智模型或单独配置 OpenAI 兼容接口；
- 情绪分析使用“模型 + 词库兜底”或完全离线的本地词库；
- 情绪模型与总结模型共用、复用小智模型或单独配置。

模型密钥保存在被 Git 忽略的 `analysis_config.json`，接口只返回“是否已设置”，不会返回密钥。启用模型时对话文本会发送到所配置的模型服务；纯词库模式不发送。情绪与留意标识只是文本线索，不是医学或心理诊断。

如果 RDK 地址变化，只修改 `RDK_BASE`，不需要修改代码。
