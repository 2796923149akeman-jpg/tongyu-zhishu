## 2. RDK X5 链路

| 检查项 | 操作 | 预期 | 实际 | 结论 |
|---|---|---|---|---|
| 视频流 | 打开 `/api/rdk/video_feed` 或监控页 | 画面持续刷新 | | |
| 行为状态 | 读取 `/alert_status` | 返回 `alert_type` JSON | | |
| 摔倒告警建事件 | 令 `alert_type` 从 normal 变为 fall | 事件页出现一条待处理事件，来源 rdk | | |
| 自动抓拍 | 查看事件详情“事件证据” | 显示抓拍图与证据时间，处理记录含抓拍结果 | | |
| 抓拍失败重试 | 断开 `/snapshot` 后制造告警，再恢复并点“重新抓拍证据” | 失败显示原因，重试后显示证据 | | |

## 3. STM32 / 环境传感器链路

| 检查项 | 操作 | 预期 | 实际 | 结论 |
|---|---|---|---|---|
| 原始读数 | 读取 `/api/iot_payload` | 返回 `connected`、采集时间和 `properties` | | |
| 监控页展示 | 打开监控页 | 六项读数与采集时间正确，过期/离线有标识 | | |
| 环境自动事件 | 令 `eco2` 超过 1000 ppm 或 `tvoc` 超过 500 ppb | 事件页出现 `environment` 事件，详情含读数与阈值 | | |
| 数据过期 | 停止传感器上报超过 60 秒 | 出现 `sensor_expired` 事件；恢复后不再重复 | | |
| 设备离线 | 令 `connected=false` | 出现 `device_offline` 事件 | | |
| 实时红外 | 打开测温页，等待红外读数 | 显示目标温度和采集时间，可确认登记 | | |
| 设备推送入库 | 使用带 `X-Device-Token` 的请求推送 | 有效且关联学生的读数自动入库，重复 `reading_id` 去重 | | |

## 4. ESP32 / 小智语音链路

| 检查项 | 操作 | 预期 | 实际 | 结论 |
|---|---|---|---|---|
| 设备连接 | ESP32 指向电脑的 WebSocket 地址 | 设备在线，可语音对话 | | |
| 对话转发 | 对设备说一句话 | 对话页出现用户文字与助手回复 | | |
| 情绪分析 | 使用词库或模型配置 | 显示情绪标签、关注等级和来源 | | |
| 情绪事件 | 触发 watch/urgent 表达 | 事件页出现 `dialogue_attention` 事件（同一会话 10 分钟去重） | | |
| 模型回退 | 临时填错 API Key | 对话不中断，情绪结果回退本地词库并标注来源 | | |
| 家长对话 | 管理员把消息关联到孩子，家长开启对话权限 | 家长日报可看到对应孩子的对话 | | |
