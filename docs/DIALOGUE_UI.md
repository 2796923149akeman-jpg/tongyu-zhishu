# 对话与情绪页面

入口为 `/chat` 或 `/chat.html`，与其他模块同由 `dashboard/server.py` 提供。

## 统一页面结构

- 使用与实时监控、学生测温和日报一致的五项主导航，当前页标记为“对话与情绪”。
- 复用 `dashboard/health-report.css` 中的导航、基础颜色、页面标题与按钮样式；对话专用布局保留在 `chat.html`。不加载测温／日报脚本或其中的演示数据。
- 主导航与会话列表分开：前者切换模块，后者选择对话。桌面显示为并列区域，手机显示横向模块导航和上下排列的会话列表、消息区域。
- “界面设置”中的记录标题显示在页头说明和浏览器标题中；模块名称始终为“对话与情绪”。

## 保留的功能

保留设备、关键词和会话筛选，用户／助手消息区分，单句情绪标签及会话关注标记，自动刷新，界面设置，对话模型配置和本地词库／模型分析切换。

按用户反馈移除“消息角色”筛选。消息的 user/assistant 字段仍用于区分说话与机器人回复，不代表儿童身份；当前页面不能识别不同儿童。

本次只调整展示结构与样式，消息接收、后台分析和模型配置接口没有改动。对话页仍只允许在服务电脑本机访问。

## 验证记录（2026-10-28）

使用独立端口与隔离数据目录，浏览器用虚构测试消息和拦截的模型接口验证，没有使用真实聊天记录或密钥。

- 1440、1024、820、390、320 像素宽度下检查页面，未出现整页横向溢出；模型与界面设置弹窗可操作。
- 五项导航及样式资源返回正常，可从学生测温切换到对话页并返回；两页侧栏的宽度与背景样式一致。
- 关键词、设备、会话筛选正常，情绪标签和关注数量正常；移除角色筛选后复查消息渲染与设置交互。
- 界面设置保存后刷新保留；模型及情绪设置提交仍使用原接口，空密钥保持原语义。
- 消息接口失败时保留已显示的对话并提示失败，恢复后重新显示连接成功。
- 现有 26 项单元测试通过，仓库检查通过，浏览器无未处理 JavaScript 异常。

本次验证不包含真实设备语音或模型服务端到端联调。
