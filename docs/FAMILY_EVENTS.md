# 家长端安全事件说明

更新日期：2026-11-04

页面：`dashboard/family-events.html`

## 访问规则

- 家长账号由管理员在展示设置页创建或修改绑定。
- 一个家长账号可绑定 1–20 名学生。
- 家长登录后进入家长工作台。管理员可以逐个账号开放安全事件、截图、个人日报和日报内的对话。服务端按绑定的学号和当前权限校验。
- 普通查看者和未登录用户不能进入家长事件页。
- 商家账号由管理员创建，仅能读取室温、湿度、eCO₂、TVOC 和红外环境温度等环境传感器字段。

## 事件可见条件

家长事件接口只返回同时满足以下条件的事件：

1. 事件状态不是 `false_alarm`；
2. 老师已经完成学生关联，`parent_visible_at` 非空；
3. 事件参与学生与学生绑定列表有交集。

多人斗殴事件会按当前家长的孩子过滤 `participants`。家长不会看到同一事件中其他孩子的
姓名和学号。老师和事件源填写的内部备注、自由文本详情不会原样下发，家长端只显示按事件
类型生成的通用说明。未关联、误报及其他家庭的事件统一不出现在列表；直接修改 URL 也无法读取。

## 截图

页面通过 `/api/family/events/{id}/snapshot` 读取截图。服务端每次校验事件归属和截图权限。
新建家长账号时截图默认关闭，已有账号沿用原来的截图访问权限。截图为现场原始帧，可能包含其他学生，管理员应先核对画面再授权。

## 日报与对话

- 管理员在对话页逐条点击“关联学生”，核对身份后选择孩子。家长只会在对应孩子的日报中看到已关联、当天且已授权的消息。
- 家长日报按孩子和日期查询，显示当天测温和已开放的安全事件与对话。园方日报可按班级或全园汇总。
- 园方日报计算截至所选日期的近 7 天体温趋势。每名学生每天取最后一次登记值，图中显示平均值和样本数，缺测日期断线。图表可随日报打印或用浏览器另存 PDF。

## 使用流程

1. 管理员先在“展示设置 → 家长账号”导入学生名单并创建家长账号。
2. RDK 检测到摔倒或斗殴，事件页自动创建告警并尝试获取现场截图。
3. 老师在事件详情填写学生姓名。摔倒填 1 人，斗殴用空格分隔至少 2 人。
4. 关联成功后，家长在工作台看到已开放的事件和截图。误报撤回后需重新关联才会再次对家长开放。
5. 家长端每 5 秒同步一次，页面隐藏时暂停轮询。

## 当前边界

- 本功能提供应用内家长事件箱，不包含短信、微信或系统推送。
- 旧版关联记录会保留在园方事件详情。老师重新确认关联后，相关家庭即可查看。旧版 RDK 若缺少 `/snapshot`，会尝试从 MJPEG 视频流抓取一帧。
- 姓名来自学生名单；同名时必须使用 `姓名@学号`，不能猜测归属。
