# 家长账号与家长端说明

更新日期：2026-11-04

负责文件：`dashboard/parent.html`、`dashboard/access_control.py`、`dashboard/server.py` 家长相关接口、`dashboard/admin.html` 家长账号区域。

## 目标

摔倒/斗殴事件由老师在处理端确认并关联学生后，事件要自动出现在对应学生家长的
账号异常事件列表中。家长只能看到自己孩子的事件与证据画面，不能访问监控、测温、
日报等其他模块。

## 角色与绑定

- 账号角色在原有 `admin`（管理员）与 `viewer`（演示用户）之外新增 `parent`
  （家长）。家长账号由管理员在“展示设置”页创建，创建时从学生名单勾选 1–20 名
  孩子；账号数据仍保存在被 Git 忽略的 `dashboard/auth_config.json`，密码只存
  scrypt 哈希。
- 学生名单沿用 `dashboard/health_students.json`（学生测温模块的名单）。老师在
  事件详情里按姓名关联学生时，服务端先按该名单解析出学生编号，因此“关联学生”
  与“家长绑定”共用同一份名单，姓名必须一致。

## 事件流转

1. RDK 行为告警进入 `fall`/`fight` → 自动创建事件，并后台抓取一帧视频画面作为
   证据（见 [异常事件页面说明](MONITOR_EVENTS_UI.md)）。
2. 老师在 `/events` 事件详情“关联学生”输入框按姓名登记（多人空格分隔）→
   `POST /api/events/{id}/students` 校验名单并写入 `students` 字段。
3. 家长登录 `/parent` → 前端每 15 秒读取 `GET /api/parent/events`，只返回
   `students` 与自己孩子有交集的事件；`students` 字段只保留本人孩子。
4. 家长点击证据图片时经 `/evidence/{文件名}` 读取，服务端按事件归属校验：
   只有关联到自己孩子的事件证据才放行，否则 `403`。

## 权限边界

- 家长访问 `/parent` 以外的页面会被重定向回 `/parent`；调用事件、健康、日报等
  接口返回 `403`，写接口同样被拒绝。
- 家长不受“展示模块开关”影响，但也不能借此绕过：其可访问范围由路由白名单
  （`/parent`、`/api/parent/events`、`/evidence/`）单独限定。
- 家长载荷中“关联学生”处理记录的姓名会被替换为“老师已登记 N 名涉及学生”，
  避免把其他孩子的姓名透露给家长。
- 家长页面只读：没有处置、备注或关联学生的入口。

## 接口

| 方法 | 地址 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/admin/parents` | 管理员 | 列出已创建的家长账号与绑定孩子 |
| POST | `/api/admin/parents` | 管理员 + CSRF | 创建家长账号，`student_ids` 必须来自名单 |
| GET | `/api/parent/events` | 家长 | 绑定孩子信息与关联到孩子的事件 |
| GET | `/evidence/{文件名}` | 登录用户 | 家长仅限本人孩子事件的证据 |

字段示例见 [API 文档](API.md#家长账号接口)。

## 验收步骤

1. 学生测温页导入名单（含陈小满、王一诺）；在展示设置页为“陈小满”创建家长
   账号并记录密码。
2. 制造一条 `fall` 告警，确认事件自动入库且带证据画面。
3. 以管理员在事件详情输入“陈小满 王一诺”并点击“关联学生”，确认姓名标签与
   处理记录更新。
4. 退出后用家长账号登录，确认直接进入“孩子的异常事件”，事件列表包含该事件，
   证据图片可查看，且只显示陈小满的名字。
5. 在地址栏访问 `/events`、`/admin`、`/api/events`，确认分别被重定向或返回
   403。
6. 为“王一诺”创建家长账号，确认能看到同一条斗殴事件但只显示王一诺的名字；
   陈小满的家长看不到王一诺专属事件的证据。

## 当前限制

- 家长账号的删除、改密尚未提供界面；账号数量沿用全局 200 上限。
- 家长端只做只读展示，不含与老师的留言互动。
- 同名学生在名单中无法唯一确认时会拒绝关联，需要老师按名单区分后再登记。
